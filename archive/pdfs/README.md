# Archived PDFs

Original Jordan-facing PDF documentation. Some content is now
superseded by `docs/GUIDE.md` and `docs/TROUBLESHOOTING.md`. Kept
because the wiring and pinout PDFs are still useful as field
references.

| PDF                              | Status                                                                                |
|----------------------------------|---------------------------------------------------------------------------------------|
| `WIRING_DIAGRAM.pdf`             | Still current. SYS TEC DB9 to OBD-II / X437 pin map.                                  |
| `PINOUT_VERIFICATION.pdf`        | Still current. Multimeter and sniffer first-time setup.                               |
| `INSTRUCTION_MANUAL.pdf`         | Mostly superseded by `docs/GUIDE.md`. Windows install steps are still valid.          |
| `IMPLEMENTATION_GUIDE.pdf`       | Superseded by `docs/GUIDE.md`. Mode tour now lives in the v4.1 GUI itself.            |
| `FLASH_AND_TROUBLESHOOTING.pdf`  | Re-flashing the EPAS rack. Only relevant if the rack reverts to stock firmware.       |
| `FLICKER_TROUBLESHOOTING.pdf`    | Superseded. Theory A/B flicker matrix; replaced by Theory C in `docs/TROUBLESHOOTING.md`. |
